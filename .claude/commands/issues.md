Fetch open issues from the GitHub repository `aulismedia/pdf-modernization` using `gh issue list --repo aulismedia/pdf-modernization --state open --assignee ""` to find unassigned issues. Pick all open issues and assign them to yourself using `gh issue edit <number> --repo aulismedia/pdf-modernization --assign @me`. Then, read each issue's full details with `gh issue view <number> --repo aulismedia/pdf-modernization`, implement the requested changes, and finally, close the issue with `gh issue close <number> --repo aulismedia/pdf-modernization --comment "Done."`. Commit the changes with `git commit -m "<description>"` but do not push to the repository.
